UAV Cue App

En enkel Python-applikation som visar instruktioner på skärm och spelar upp ljud. Användes för att studera arbetsbelastning i en flygsimulator.

⸻

Krav
	•	Python 3
	•	pygame

⸻

Installation
	1.	Installera Python: https://www.python.org/downloads/
(Viktigt: välj “Add Python to PATH”)

	2.	Installera pygame för att kunna spela ljud:
Öppna Terminal / Command Prompt
	pip install pygame


⸻

Kör programmet
	1.	Öppna Terminal / Command Prompt
	2.	Gå till mappen (i detta fall på skrivbordet):

Mac:

	cd ~/Desktop/UAV_Cue_App

Windows:

	cd Desktop\UAV_Cue_App

	3.	Starta programmet:

	python uav_cue_app_audio_timed.py
Eller
 
	python uav_cue_app_timed.py


⸻

Användning
	•	Tryck SPACE för att starta/stoppa
	•	Instruktioner visas automatiskt
	•	Ljud spelas upp om det finns
